# Tag 2: Kontrollstrukturen und Funktionen

## Behandelte Themen

1. **Verzweigungen** (Einheit 08). `if`, `elif`, `else`, Vergleiche, `and`.
2. **Schleifen** (Einheit 09). `while`, `for`, `range` als Indexschleife, `continue`, `break`, `else` an der Schleife, `pass`.
3. **Funktionen** (Einheit 10). `def`, Aufruf, `return`, Rückgabe `None` ohne `return`.
4. **Parameter und Sichtbarkeit** (Einheit 11). Position, Schlüsselwort, Standardwert, lokal, global.

## Wichtige Konzepte

- `=` weist zu, `==` vergleicht.
- `else` an einer Schleife gehört zum Ausbleiben von `break`.
- Ohne `return` kommt `None` zurück.
- Eine Zuweisung in der Funktion erzeugt einen lokalen Namen.
- Eine Liste als Standardargument ist ein gemeinsames Objekt aller Aufrufe.

## Stichpunkte

- Der Mittelwert ist `sum(values) / len(values)`.
- `raise ValueError` weist eine leere Reihe ab.
- `global` kommt im Beispiel vor. Für eigene Funktionen reicht meist ein Rückgabewert.
- `check_status`, `check_count_until_above`, `check_mean` und `check_shift` prüfen die Übungen.
